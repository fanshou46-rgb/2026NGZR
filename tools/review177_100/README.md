# 1.7.7 对照1.6.7与独立100题的审核工具

正式代码固定在 `68fe263b`，正式比较臂为1.6.7、1.6.7-200ms和1.7.7。三个消融共享独立实验副本，以 `RDFW_AUDIT_ABLATION` 选择模式；没有修改已有版本目录，也不创建1.7.8。

生成阶段在Windows Python 3.10+运行；Linux SDK执行在Ubuntu 18.04、GCC7.5运行。默认SDK为此前1.7.7实测的 `/tmp/env-release-2026-search`，可用 `RDFW_AUDIT_SDK` 指向经哈希核对的同版SDK。桌面同名SDK的库曾由较新编译器构建，不能不经核对直接混用。

执行顺序：

1. `prepare.py`：冻结原版本哈希，建立独立实验源码。
2. `generate.py`、`audit_bank.py`：新题、参考、指南和精确反事实审计，不运行机器人。
3. Linux `pipeline.py build`：统一编译，原始及实验默认模式全套检查、四模式专项检查。
4. `pipeline.py preflight`：180个官方SDK参考入口；任一失败即停止，无机器人新题运行。
5. `pipeline.py equivalence`：4道短Stage1控制，IT/NT核对默认实验与原始版本动作及基础指标。
6. `pipeline.py freeze`、`pipeline.py matrix`：冻结全部输入、工具、源、SDK和二进制；6726次串行轮换实测。
7. `analyze.py`：全部配对、全部退化、重复波动、按场景成组的置信区间和原始轨迹入口。

6726次由新题4320、历史71输入1704、已见52题624、非法题60及历史平台异常18组成。另有180次参考、16次默认等价检查，单列。种子为2026100403/0404/0405，再重复0403；重复轮不加入独立种子置信区间。

脚本拒绝覆盖未登记的执行目录。`results.jsonl`每次追加并同步保存，续跑只跳过已有完整结果；遇到中断遗留目录必须先登记原始状态，不能悄悄删除或重跑替换。SDK临时工作目录位于Linux文件系统，执行结束后压缩动态文件、保留所有日志，再转存仓库。共享SDK文件按原字节哈希引用，原始SDK不改写。

neutral为冻结的中性启发式：正权重未知假设等权、问答似然不区分世界、不进行数值回答后验，未知可见性固定0.5；硬确认事实及硬排除保持。no_ask只关闭问答数值更新，保留新增回答的支持与待验证线索。legacy_visibility保留问答更新，只将联合区间替换成旧式单物位置概率。禁用模式不是已校准概率模型，也不是禁用必要感知。

实验源、原始评分、字节收据、所有作者预检草稿与编译失败保留在本轮validation目录。发布包与报告给出哪些证据归档、哪些SDK共享文件仅作哈希引用，不把作者真值送进机器人。
