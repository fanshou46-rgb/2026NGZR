# 出题指南逐项复核与修订

复核日期：2026-09-28。范围：本次生成的 `2026_comprehensive_200` 题库。对照本地《出题指南 2025》《规则 2026》及用户列出的检查要求，逐份检查 XML、环境事实、指令、自然语言和参考动作。没有重新审计用户列出的各队原题。

**结论：上一版确实存在系统性错误，不能继续使用上一版“全部通过”的结论。现已修订全部 180 道正常题；独立指南检查为 180/180 通过。**

## 上一版发现了什么

| 问题 | 受影响正常题 | 修订 |
|---|---:|---|
| 每题 10–18 个目标，超过要求的 3–7 个 | 180/180 | 每题改为 7 个目标，重新编排任务与参考动作 |
| 一条 near 涉及两个小物体，并对 Y 增加 color | 180/180 | 删除此类设计；near/on/puton 的 Y 只绑定大物体，不出现 color Y |
| open/close、putin/takeout 缺规定的 type 条件 | 180/180 | 按附录 B 补全 type X/Y container，并核验 cond 顺序 |
| 环境中容器的 type 写在 at 前 | 180/180 | 改为 sort → size → at → type → opened/closed；第二阶段允许位置事实按规则移至 mis/err |

上述四行按错误家族归并。机器报告将“小物体—小物体 near”分别记录为双小物体、关系类型、color Y 三个检查项，共六个错误代码。它们是同一批题中的重叠问题，不能相加成题数。

旧版已经按 `40G+20C=900` 配分，因此虽然目标数量违规，**旧版并不存在毛分超过 1000 的问题**。上一轮遗漏的是指南合规检查；可执行性检查通过不能替代格式审查。

## 保留复杂度的方式

- B01 的两个最终 pickup 目标和一条禁止上托盘约束共同确定槽位分配；反事实题只交换禁上托盘的对象。8 对题保持相同初态和其他指令，交换参考方案后均会违约。
- C04 改为三个分别描述的最终 pickup 目标。两个槽位最多同时满足其中两个，容量冲突成立，且每条指令只涉及一个小物体。
- C03 保留“打开一个受保护容器，换取多个目标”的收益取舍。
- C05 改为五个安全目标、两个风险目标，并保留每个风险目标的两条损失约束和共用闭门约束。
- D01 使用两个初始分散的可移动 goto 目标，先聚集再结束；D02 使用三个不同固定终点，最终只能满足一个。
- 可见性、查询价值、最终双携带各覆盖 20 份 XML；单条件翻转覆盖 16 份 XML。手与托盘初始占用、开关门空手前置条件、颜色绑定和门状态恢复继续单独检查。

- 《出题指南 2025》第 1–2 页：human 编号、环境字段顺序、颜色、禁止单条指令涉及两个小物体、IT/NL 对应等；附录 B：容器条件与 cond 格式。
