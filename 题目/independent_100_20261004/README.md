# 1.7.7 独立100题对照题库

70道可全解题、20道结构取舍题、10道故意非法题。90道合法题组成45组Stage1/Stage2配对，每题7目标、30条不同约束，名义毛分880；完整协议报文小于3900字节。

题型沿用此前18个正常方向，但新增取出来源与运输目的柜的共享依赖、初始已满足终点的破坏/恢复、同类颜色绑定及运输/携带联合收尾。仅更换编号、颜色和地点的重复不计为新结构。四组反事实仅改变一条约束；它们在统计中成组处理。

- `catalogue.json`：全部100题、信息扰动、哈希及统计簇。
- `cases/stage1`、`cases/stage2`：各45题，IT/NT分别运行。
- `cards`、`references`：45份中文题卡、真值参考与比较方案；参考不是自主Stage2策略。
- `invalid`：5种格式/指令错误、5种IT/NT不一致，单独诊断，不计能力分。
- `offline-audit.json`：生成阶段的指南和动作重放检查。

生成与独立审计工具位于 `../../tools/review177_100`。`generate.py`拒绝覆盖已有题库；重生成应使用新的输出副本，不覆盖已观察成绩的输入。生成程序不读取机器人得分。运行中的参考执行与机器人评分证据、全部退化、重复波动和模型贡献结论见 [本轮评测](../../validation/review177-100-20261004/REPORT.md)。

参考JSON中的 `platform_executed=false`、`scores_measured=false` 是生成时的设计快照；实际SDK预检状态以评测目录的 `preflight-audit.json` 为准。
