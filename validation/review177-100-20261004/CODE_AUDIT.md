# 冻结1.7.7代码审核

代码对象为68fe263b的src1.7.7。本文件是源代码审核，不把尚未运行完的矩阵写成成绩；最终实例、排名、退化与修复优先级由REPORT.md和完整轨迹补充。

## 概率实际进入哪些决策

`visibility_forecast.cpp:6–79`枚举至多32个局部场景，将显式at、确认inside边、槽位与柜门放入同一场景；先验仍来自单物位置分布。有效Sense逐物条件化，遗漏支持进入residual。它不持久维护完整世界的联合动作后验。

`probe_layer.cpp:139–145`对多个相关目标取可见性下界的最大值，描述至少获得一个相关ID观察的保守机会。`475–511`以此乘目标机会值，扣继续成本、探测动作、每项40分终态损失和约束风险；非正收益会过滤候选。该乘积不是完整任务收益的已证明下界：观察到一个相关ID并不意味着完成机会值中所有目标。

`probe_layer.cpp:514–529`物理观察排序仍优先回答路线提示、候选类型、事实数量、潜在目标值和成本；没有按物理观察的expected_gain排序。模型可以改变是否探索，未必充分改变先探索哪里。`475–484`针对同一目标/地点至少调用两次VisibilityProbability，存在可核对的重复构造，但实际耗时贡献不能由墙钟总分差直接推断。

`answer_planning.cpp:62–76,129–206`通过确认事实、搜索预算、路线资格、期限及公开假设构造问答分支。多正确答案但未知SDK选答顺序的候选被拒绝。`information_planner.cpp:6–52`使用后验匹配概率比较验证路线，评估问答的相对直接路线价值；因此关闭问答数值模型影响问答选择与回答后路线，不只影响一条赋值。

## 事实、执行与恢复边界

`rdfw.cpp:1958–2055`每次组合搜索限25ms、累计限100ms。搜索只要超预算或任一投影失败，就在检查已有best_safe/best_broken之前整体回退；随后没有正收益单任务时会停止。应审计是否丢弃已经找到且完整、证据闭合的可行改善计划，而不是将搜索未完成等同于所有组合无益。

Stage2在`rdfw.cpp:1995–2009`遍历所有根候选的所有动作，只要任何根含观察、未知位置/inside/柜门就放弃整轮组合。未被选择的不确定任务可能阻断其它已确认任务的安全组合；后续需要按候选或具体组合筛选可执行支持，不能把所有未知事实直接当确认。

首轮新题A01-02-s1 IT已出现可复查实例：1.7.7五步完成蓝物送达，实际G3/C30/K14/base706、0.635秒停止，日志余4366ms、单任务−12/−14及search_incomplete_or_timeout。同轮1.6.7-200ms继续运输和关门，SDK正式分876；新版792。这里是完整信息Stage1，不能把退化归因于回答噪声；最终报告以全部种子/重复和官方终态再汇总。

实际输入或Ask回答不是物理真值。确认的独立at、inside、手/托盘与动作反馈必须继续保留；消融不得回滚这些语义修复。实验只改三个概率模块，禁止改变任务生成、资格、约束、安全授权、终态损失和200ms预留。

`answer_planning.cpp:33–37`对未知父容器位置、柜门或非空手直接拒绝单条验证路线，尚未构造“先腾手/验证柜门，再根据成功失败继续”的完整策略。`probe_layer.cpp:436–440`开柜探测仅为确认关闭且位置已知的柜生成。放宽判断本身不是修复：必须同时提供动作成功、失败及恢复分支。

`probe_layer.cpp:500–507`离开已满足goto的损失逐项扣40分，修复了无条件假设返回的乐观估计；缺少返回路线时会保守停止。后续应把带返回的完整可执行路线纳入同一收益比较，而非简单降低探测门槛。

`probe_layer.cpp:150–156`有三次任务尝试上限，`probe_layer.hpp`还有总探测成本及次数限制。状态证据变化后哪些失败任务能重新进入候选，需要结合实际停止轨迹核对；反复盲试和永久屏蔽都不是合理的通用恢复。

## 概率与耗时尚未校准

`belief_state.cpp:14–19`给初始描述额外一半权重；`observation_model.hpp`默认回答质量为0.6/0.3/0.1；`visibility_forecast.cpp:53–59`使用0.75和0.5覆盖折扣。它们是开发假设。区间相对于该先验成立，不意味着已覆盖实际成功频率。

单次观察0/1是否落入区间不是概率校准检验。被选中的候选反馈有选择偏差，未执行候选不能补造结果。真实SDK耗时、推理耗时和固定动作估计应分别测量；同种子不同动作还会消费不同随机数，不能宣称后续收到相同回答。
