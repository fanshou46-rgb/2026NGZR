# src1.8 实现与最终验证

测试：2026-10-03；报告整理：2026-10-04。同步基线为 upstream/main `4b0f3f3e8f0f777be3bf184a149572a22f03d31e` / src1.7.1，分支为 `feat/v1.8-belief-probe`。旧版本、题源和官方 SDK 保持原样。

本轮完成独立 src1.8 的实现和验证。相对 src1.7.1，完整历史输入基础分增加 2,349、目标增加 73；仍有逐题退化，多种子关键题超时增加，与 src1.6.7-200ms 的关键题直接对照仍落后。本版本保留为实验候选，尚不足以替换比赛基线。

## 实现结果

- 独立 LocationBelief 保存位置/容器/未知概率。AskLoc 用带噪观测更新，只提供弱线索；未知、非法和重复回答不制造可信事实。真实阴性 Sense 只排除已证明不存在的外部位置，不推断关闭容器内部为空。
- Probe 在 Stage 2 停滞时可以普通观察、单次询问或有条件地开柜观察；得到一次真实反馈便重规划，失败不继续预设动作链。可用回答须有相关验证才能再次询问；not_known 可以有界重问。
- 探测次数限制局部生效，避免一个地点无信息后关闭整个探索层。每题新增 Probe 总次数 8、成本 32；同普通 Sense 地点/同开柜容器最多 2 次，同对象 Probe 询问最多 3 次。这些限制只属于新增 Probe，普通任务感知保留任务预算。
- 保留普通 Sense 完整原排序：事实覆盖、目标机会、成本、耗时、稳定标识。概率用于资格筛选和询问排序。预留信息之后的执行及必要 GOTO 恢复成本/时间。
- 对至少 200 分目标机会，Move+Sense 可有界交换最多两项不同记分约束；每项预留 20 分最坏损失，预计净收益须为正。物理前提、原子动作权限、已知目标损失和完整预算继续检查。
- Stage 2 在物理输入已确认时扩展候选资格和有界任务组搜索；成功次数不占失败重试额度，被后续动作破坏的目标可恢复。UNKNOWN 输入保留保守资格检查。
- 修复 Plan/Fini 结束竞争：SDK 超时后可能在规划线程未退出时调用 Fini，旧实现同时释放任务和对象。新版先发停止信号，等待规划退出再清理，禁止再发起 SDK 动作；下一题可以重新规划。SDK 未修改。

完整流程见 [ROBOT_FLOW.md](ROBOT_FLOW.md)，参数/构建见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，复核和不利试验见 [PLAN_REVIEW.md](PLAN_REVIEW.md)，GitHub 参考见 [GITHUB_INSPIRATION.md](GITHUB_INSPIRATION.md)。

## 概率模型的下一步

目前概率是显式假设下的近似：询问模型借用官方 0.6 正确、0.3 随机、0.1 未知规则，但本地回答域不完整；先验偏置、可见性、后续计划价值和耗时未学习校准。`expected_gain` 不是完整 POMDP 价值，整体收益不能全部归因于概率。

1. 分离询问、外部 Sense、开柜 Sense、动作成败的观测模型。可信事实单独保存；回答准确率训练只使用后来有真实验证的回答，未验证回答不能标成正确。
2. 枚举“回答 A/B/未知”分支，各自估算问完后真正可执行的完整计划，再按观测概率加权，纳入成本、约束和剩余时间；保留已测有效的 Sense 顺序。
3. 用实际验证反馈拟合回答、可见性与耗时分布，用独立留出题检查校准；同一时限、多种子同时验收基础分、官方分、G/C/K、超时和退化。
4. 再试 DESPOT/POMCP 风格有限场景搜索。采样世界独立于 SDK 隐藏真值；搜索严格有界，有确定性回退。

GitHub 可借鉴 [pomdp-py](https://github.com/h2r/pomdp-py) 的观测模型与 belief 更新、[DESPOT](https://github.com/AdaCompNUS/despot) 的 C++ 场景搜索、[BasicPOMCP.jl](https://github.com/JuliaPOMDP/BasicPOMCP.jl) 的在线采样与预算。具体代码入口和适配理由见参考文档；本轮没有引入外部依赖。
