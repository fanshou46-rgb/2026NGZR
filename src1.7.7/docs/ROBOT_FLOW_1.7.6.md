# 1.7.6 从输入到停止的决策流程

以下描述当前真实生产代码。独立 `JointPolicySearch` 尚未替换生产 Probe，不能把实验内核的能力算作机器人已经具备的能力。

1. **清理上一题。** `PlanImpl` 重置截止计时、动作成本、约束记账、探索历史和确认事实，打印版本 1.7.6。规划线程生命周期锁避免 SDK 退出时仍访问已清理状态。
2. **读取公开环境。** 解析机器人、物体属性、地点、槽位、柜门和逐容器关系。Stage 1 初始事实可确认；Stage 2 的初始描述可能缺失/误导，保留为提示。环境真相和作者参考路径都不提供给规划器。
3. **解析目标与约束。** IT 读结构化指令，NT 使用词表与语法解析。按 sort/color/type/显式 ID 绑定对象，逐条隔离非法指令，进行题目前置检查。目标是否完成由当前事实判定，不由 `isEnable`、执行过某动作或问过某物品判定。
4. **应用合法推导。** 必须满足的信息约束可以提供带依赖的推导。依赖事实变化、约束失去资格或不确定时，推导不再授予已确认终态。独立动作证据和弱初始/询问提示分开保存。
5. **检查停止条件。** 目标全部确认完成或时间耗尽则停止；多个 goto 会在主循环中暂缓，再评价尾部汇总路线。剩余预算不足以覆盖动作估时加安全余量时不开始该候选。
6. **模拟每个任务。** 在保存的世界里运行候选，记录动作、费用、估时、目标/约束得失。模拟结束后恢复所有状态，包括 1.7.6 的关系表、槽位排除和容器缓存；模拟不调用 SDK。只有路线完整、证据资格满足、边际收益为正且预算允许的单任务可被选择。
7. **必要时尝试任务组。** Guard 自动比较有限任务组与单任务，在公开前提和允许的约束损失内考虑“先做一步再恢复其它目标”的组合。公开槽位或动作前提不可靠、需要观察后分支的组合仍可能被拒绝。这是当前完整路线缺口之一。
8. **执行获准的路线。** 每次真实尝试都计成本，包括失败。成功 TakeOut 只把指定 inside 边变为否；PutIn 只把指定边变为是；拿起、放下、上/下托盘不删除其它关系。Open/Close 成功确认该柜门、同地点和空手。后续动作继续检查资格与时间，SDK 返回后再重新规划。
9. **确认送达终态。** PutDown 成功只证明物品不在手中，托盘仍可能保留同物。需要补证据时，在确认空手前提下尝试 FromPlate：成功后再 PutDown；失败证明托盘不是该物品。未知空手不能由这个失败推出托盘排除。该尝试仍收费，也保留失败日志。
10. **停滞时进入 Probe。** 枚举原地 Sense、移动后 Sense、开柜后 Sense、AskLoc。检查与目标相关的未知事实、公开前提、约束风险、重复上下文、累计探索成本/次数和时间。`MustChooseOne` 当前只记录旧建议，不执行随机任务。
11. **评价询问后的路线。** 当前使用位置分布和 SDK 噪声观察模型，按可能回答展开后续验证路线，并从收到回答后的分布中选路线；不能按隐藏真实世界选路线。其它探索仍有启发式机会值；并不是完整联合状态最优策略。
12. **接收公开观察。** Sense 的 ID 集合不能证明唯一容器归属、柜外或不在槽位。Ask 是弱提示，不能因另一个正关系或 at 回答撤销已确认关系；确定不存在的目标边可拒绝冲突回答。概率分布影响候选排序，不能直接写成确认事实。
13. **反馈后重规划。** 比较取得了哪些相关证据、是否恢复任务资格、实际目标/约束/费用与候选预测的差异。只增加世界版本号或重复提问不视为有效信息。关系和槽位排除参与上下文，避免错误复用探索结果。
14. **汇总并退出。** 无合法有收益候选且无可执行 Probe、或剩余时间不够时正常停止，报告内部 G/C/K/base 和停止原因。官方 SDK 根据真实终态评分；内部报告必须与官方逐格对照，不能自行作为实际成绩。等待规划线程结束后再清理资源。

## 阅读代码的位置

- 主循环与动作包装：`rdfw.cpp` 的 `PlanImpl`、`ExecuteMainTaskLoop`、`TryGuardedDecision`、原子动作及 `GetSmallObjectStatus`。
- 指定容器关系：`containment.cpp`；事实查询/快照：`canonical_state.cpp`；终态：`terminal_checker.cpp`。
- 探索候选、授权与公开反馈：`probe_layer.cpp`；回答分支与验证投影：`answer_planning.cpp`。
- 概率分布/观察噪声：`belief_state.cpp`、`observation_model.cpp`；独立联合模型：`joint_world.cpp`。
