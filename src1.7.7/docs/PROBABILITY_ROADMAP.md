# 1.7.7 的新增内容与后续路线

当前入口为 [1.7.7 概率说明](PROBABILITY_1.7.7.md)、[304 次生产对照](../../validation/review177-20261004/REPORT.md) 和 [每步实际决策](ROBOT_FLOW_1.7.7.md)。下文保留上一版本制定的路线；其中可见性模拟、独立 at、residual 和探索目标损失已在本轮部分落实。

| 版本 | 新增内容 | 完成边界 |
|---|---|---|
| 1.7.2 | 单物位置分布、有限探索、观察后重规划 | 不能表达 at、多父和双槽共存 |
| 1.7.3 | 询问噪声、回答分支及验证路线价值 | 回答不授予真值，仍无完整联合世界 |
| 1.7.4 | 独立 JointWorld、联合 belief、有界反馈树；收紧槽位证据 | 内核未替换生产，缺失送达确认路线引发退化 |
| 1.7.5 | 必要放置验证、移除 Sense 容器推断；内核支持双槽和多父 | 生产仍会清独立 inside，完成数可能高报 |
| 1.7.6 | 生产逐容器关系、单边增删、空手下 FromPlate 失败排除 | 探索仍可能丢 goto，模拟遗漏 at 共存 |
| 1.7.7 | 独立 at、终态捷径修正、联合可见性区间/residual/公开观察更新、扣目标损失 | 物理 Probe 已接入局部概率；持久动作后验、完整收益树及校准未完成 |

接下来先完成公开联合状态与动作后验，再让同一反馈树覆盖直接任务、观察、失败和恢复；收益统一包含实际终态、约束、成本、耗时及封顶。需要补未知门和多正确答案顺序，并保留执行资格。最后冻结开发参数，用独立新题校准与完整比赛回归，避免从已选候选的反馈推断所有候选的成功率。

## 1.7.6 制定的路线记录

本版修复关系事实与失败反馈的基础，并未完成联合概率策略的生产接入。改变概率参数不能补救错误的动作模型；先让模拟与官方动作语义一致，再比较期望收益。

- 1.7.2：位置分布、有限探索、观察后重规划。
- 1.7.3：询问噪声模型，展开收到回答后的验证路线。
- 1.7.4：独立联合场景与反馈树；生产槽位证据收紧，暴露缺失的验证路线。
- 1.7.5：增加放置验证，取消 Sense 的容器归属推断及无关 inside 终态门槛；独立联合内核支持双槽同物、多条 inside。
- 1.7.6：生产关系表、按目标容器增删关系、准确取出终态、失败反馈排除指定托盘物品，减少必要的放置确认动作；关系参与模拟恢复、异常回滚与探索缓存。

## 下一步应实施的顺序

当前最先修复的生产问题来自 h03 的真实退化轨迹：送达完毕后，为了柜内线索 MoveSense 离开桌边，未实现取出，也没有恢复 goto。探索候选 expected_gain=11.8，而已完成 goto 丢失值为 40。先让所有探索计算真实终态损失，并在需要返回时预留恢复动作/费用/时间；若无法证明后续完整可执行，就给保守收益界。不能用更高的启发式信息价值掩盖这个差额。随后再扩展如下联合概率路线。

返回投影中的 DryRunSenseIds 仍用单 inside/柜门过滤，错把拥有 explicit at 的杯子隐藏，模拟返回误报丢送达、utility=−5；独立当前静态库反例已复现，相同初态直接 SDK 返回则 G2/K5/base75。所以下一版必须先修模拟可见性与完整状态；直接放开 goto 的负收益门槛会掩盖模型错误。

1. **完整事实表示和先验入口。** 将显式 `at` 与“能在该地点看到物品”分开；世界使用机器人地点、手/托盘、每个物品的独立 at、所有 inside 边、柜门。一个物品可同时 at、多 inside、双槽同物。1.7.6 的旧路线字段仍只保存一个代表容器，不能把它当作完整世界。现有单物位置分布也不能表达这些共存状态。
2. **覆盖诊断。** 从公开初始输入和当前证据构造有限联合支持，保留未枚举的 residual mass。零概率反馈记录为支持缺失，触发重建或降级；不能将错误答案强制改成真值，也不能用 SDK 隐藏真相初始化机器人。对有未覆盖质量的策略只报告保守界，不能宣称全支持最优。
3. **动作和反馈一起更新。** 每个真实动作提供成功/失败、每次 Sense 提供 ID 集合、每次 Ask 提供带噪声回答。更新规则为先按转移预测，再乘观察似然并归一化。已确认空手时，FromPlate(A)=false 排除 tray=A；空手不确定时仍保留多个失败原因。重复事件不能再次更新同一证据。
4. **完整路线与联合奖励。** 用同一个反馈树评估停止、直接任务、询问后行动、开柜后感知和槽位验证。奖励包含真实终态目标、约束损失、所有成功/失败尝试成本、耗时与逐题得分封顶。优先比较相对停止的收益，而不是信息熵下降或理想成功分支。未知柜门造成完整路线缺失，需要建模公开 Open/Close 反馈，不能直接假设门已确认。
5. **与执行授权闭环。** 概率只排序候选，不写入确认事实。选出策略后重新核对公开前提、允许承担的约束风险、探测次数/成本和剩余时间。一次公开反馈后重新规划，禁止根据隐藏世界编号选择后续动作。预期的失败反馈仍真实收费，日志保留其失败性质。
6. **概率与耗时校准。** 用独立数据估计回答正确率、不同反馈条件与动作延迟；按误导回答、未知槽位、柜门、关系共存分别检查。参数在开发集确定后冻结，新结构题只用于评价。比较实际成功频率与预测概率、策略收益与实际基础分，并保留所有退化。

每步完成后需要同时报告基础分、正式分、真实 G/C/K、时间、硬截止、内部高报/低报以及未覆盖观察。一次有限题集改善不能替代完整赛题回归；已有测试题再次使用时应称为回归集。

## 已查阅的开源实现
