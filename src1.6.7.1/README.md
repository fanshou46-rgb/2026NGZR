# src1.6.7.1：规划退出与清理同步

从 `HistoryVersion/src1.6.7` 原版独立复制，落实强化计划的 H1 工作包。

官方 SDK 的 `Plug::Run()` 使用限时线程等待，期限到达后可能在 Plan 仍运行时调用 Fini。原版清理与规划没有互斥保护。本版让 Fini 先递增退出代次，再等待 Plan 的生命周期锁；Plan 在输入、停止门控与动作记账边界检查退出请求，并通过专用异常正常展开。清理在在途调用和内部更新结束之后执行。下一题使用新的代次；普通运行时异常继续按原行为传播。

退出保护覆盖 RDFW 内部状态。SDK 自身在 RDFW::Fini 之前发送 Fini 消息的顺序仍由 SDK 决定；在途网络调用的解除取决于 SDK 和连接，生命周期锁不能主动中断网络阻塞。

300ms 计划预留、5000ms 平台期限、排序、必要感知、MustChooseOne、约束交换和 Multi-GOTO 按原版运行。完整关系改造、反馈重试和探索改进属于后续独立版本。原版日志中的继承标签为 1.6.6；本版修正为 1.6.7.1，比较身份由源码与二进制哈希确定。

本版的八项专项检查覆盖清理等待、异常传播、取消后重用、重复题目、在途成功／异常调用和多 GOTO 标志构造默认值。同一反例也编译到未修改 1.6.7，以失败退出码 42（清理交错）和 43（构造默认值）验证原缺口。平台屏障仅存在于本地测试 stub，不进入正式客户端。

内存检查发现原 `isMultiGotoMode` 没有构造默认值，直接候选预览会在 Plan 重置前读取它。本版初始化为 false；正常 Plan 本来就先设为 false，因此该修复主要封闭预览与测试入口的未定义读取。

正式对照使用原 `题目/2026_comprehensive_200`：180 道正常题及 20 道异常题，IT/NT 两模式，SDK 种子 20260928，默认模式，串行 AB/BA。正常题成绩与非法处理分别报告；任何退化和缺失都保留。

构建和运行入口：`tests/CMakeLists.txt`、`tests/run_comprehensive_compare.py`。继承的其它测试脚本是历史工具，当前本轮以新入口和发布报告为准。
